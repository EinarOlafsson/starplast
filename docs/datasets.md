# Dataset catalogue

Sources, measurements, and coverage recorded by `starplast.datasets.REGISTRY`.
This table is generated with `python scripts/update_datasets.py`. Coverage figures
refer to the registered source or cached build, not to every possible experiment.

The catalogue covers **128 registered datasets and computed layers** across both
organisms. **Source** links lead to the registered data download or original
publication. GEO and PRIDE accessions also link to their archive records.
Computed layers link to their input datasets; missing publication citations are
marked explicitly. Raw source files are not all bundled with the Python package.
