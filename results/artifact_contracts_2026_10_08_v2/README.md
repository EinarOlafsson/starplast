# Reviewed immutable artifact pilot

Ten data-only artifacts round-trip exactly across six scorecard task types and five storage roles. Code, table, truth, exclusion, split and upstream identities are pinned. Changed code invalidates all ten artifacts; unchanged code invalidates none. Deliberate entity-order, settings, partition and fit-population changes are refused. Known benchmark entities are refused as unknown deployment, and fitting access is checked against the frozen split.

The six task payloads, model metadata and deployment data are synthetic schema fixtures; no runner or estimator was executed and no biological metric was computed. Scorecard aggregation and task-specific row adapters remain subsequent instruction-64 work. `pilot.ipynb`, `verification.ipynb`, `report.json`, `split.json` and the top-level manifest retain the acceptance evidence. Each child directory has its own complete content manifest. Original source files and runtime/calibration data remain unchanged.
