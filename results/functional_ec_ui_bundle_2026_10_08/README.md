# Prototype functional UI bundle

Executed packaging of the exactly replayed v2 EC-profile pilot. All source artifact
payload bytes were verified, and every displayed row/card retains its original
payload hash and source artifact identity. Model state remains upstream.

This prototype is retained as evidence of the packaging implementation; it is
**not the final package candidate**. Subsequent source-entry validation and
feature-exclusion review require a new v3 pilot and a newly executed bundle.
The packaged application file must point to that final reviewed snapshot.

Independent biological activity accuracy, calibrated confidence, and new verified
unknown-gene claims remain unavailable. Reference recovery never creates verified
biological negative labels for genes without annotations.
