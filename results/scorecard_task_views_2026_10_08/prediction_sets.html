Accuracy, all eligible

Hidden genes called with their true label, divided by ALL hidden genes. A gene the strategy declined to call counts as wrong.

Range: 0 to 1

Chance: about the sum of squared class shares (Cohen's chance term)

The headline for label calls. Counting abstentions as errors stops a strategy looking accurate by calling only the easy genes; coverage and precision of calls split it apart.

All eligible: 4

Coverage

Share of hidden genes that received any call.

Range: 0 to 1

Chance: not applicable (a property of the strategy, not of luck)

How far the strategy reaches. A network strategy cannot call a gene with no edges; a low coverage with a high precision of calls is a precise but narrow tool.

All eligible: 4

Accuracy among calls

Correct calls divided by calls made (also called selective accuracy).

Range: 0 to 1

Chance: as accuracy, among the genes called

How far to trust one call. Equals accuracy when coverage is 1.

Calls made: 2

Macro precision

For each true class: of the genes called that class, the share that truly are; averaged over classes with equal weight. A class never called scores 0.

Range: 0 to 1

Chance: about the average class share

Whether calls of the RARE classes can be trusted too; a strategy that only ever calls the commonest class scores low.

Macro recall (balanced accuracy)

For each true class: the share of its hidden genes called correctly; averaged over classes with equal weight. Identical to balanced accuracy.

Range: 0 to 1

Chance: 1 / number of classes, for a caller that ignores the data

Whether every class is found, not just the large ones. Compare with accuracy: a large gap means the strategy lives on the big classes.

Macro F1

Per class, the harmonic mean of precision and recall; averaged over classes with equal weight.

Range: 0 to 1

Chance: low; roughly the average class share

One number balancing finding each class and being right when calling it, with rare classes counted as much as common ones.

Weighted F1

Per-class F1 averaged with each class weighted by its number of hidden genes.

Range: 0 to 1

Chance: about the sum of squared class shares

Macro F1's counterpart that follows the class sizes; close to accuracy when coverage is high.

Cohen's kappa

Agreement between calls and truth corrected for the agreement their class frequencies alone would give: (observed - expected) / (1 - expected). No call is its own category.

Range: -1 to 1

Chance: 0

Accuracy with chance removed: 0 is no better than matching class frequencies, 1 is perfect. Comparable across labels with different numbers and sizes of classes.

Matthews correlation (MCC)

The multiclass Matthews correlation coefficient (Gorodkin's R_K) between calls and truth, with no call as its own category.

Range: -1 to 1

Chance: 0

A correlation between the call and the truth that stays honest under strong class imbalance; often the single most informative number for an unbalanced label.

Macro AUROC

For each class, the probability that a random hidden gene of that class gets a higher score for the class than a random hidden gene of another class; averaged over classes. Needs per-class scores.

Range: 0 to 1

Chance: 0.5

How well the strategy's scores separate each class from the rest, before any threshold is chosen. Missing for strategies that call labels without scoring every class.

Macro AUPRC

For each class, the area under the precision-recall curve of its one-vs-rest scores (average precision); averaged over classes. Needs per-class scores.

Range: 0 to 1

Chance: the class's share among hidden genes, averaged

Like macro AUROC but dominated by the top of each ranking, which is where calls are made; far below AUROC means good separation overall but a noisy top.

Prediction-set coverage, all eligible

Eligible rows whose prediction set contains their observed label, divided by all eligible rows. An empty set is uncovered.

Range: 0 to 1

Chance: depends on set size and label distribution; not a fixed chance rate

Inspect coverage with set size, empty-set share and singleton-call coverage. Recovering source labels does not establish independent biological validity.

All eligible: 4

Mean prediction-set size

Mean number of distinct labels in each prediction set over all eligible rows, including empty sets.

Range: 0 to the number of declared model classes

Chance: not applicable

Smaller sets narrow the answer only when coverage remains adequate. A set containing every model class provides little resolution.

Singleton-set share

Eligible rows with exactly one label in their prediction set, divided by all eligible rows.

Range: 0 to 1

Chance: not applicable

For recorded conformal label outcomes, only singleton sets produce individual label calls. This is reach, not correctness.

All eligible: 4

Empty-set share

Eligible rows with no labels in their prediction set, divided by all eligible rows.

Range: 0 to 1

Chance: not applicable

Empty sets are abstentions and coverage misses. Their native efficiency contribution is nevertheless the same as a singleton; inspect both measures.

All eligible: 4

Prediction-set efficiency

For C declared model classes, 1 - (mean(clip(set size, 1, C)) - 1) / (C - 1). Unavailable when C is less than two, classes are unspecified or the cohort is empty.

Range: 0 to 1

Chance: measured by the same procedure on shuffled labels where a null is supplied

One means singleton-sized or empty sets; zero means all-class sets. Empty sets are clipped to size one here but count as coverage misses. Inspect achieved coverage and empty-set share.

Nominal prediction-set coverage

Declared one minus conformal alpha, fixed before the final label test.

Range: 0 to 1

Chance: not applicable; a setting rather than achieved coverage

Compare with achieved prediction-set coverage and size. Source/context/exchangeability review is required; this setting is not a per-gene correctness probability.
