# Forty logo drafts, black and white

Requested 2026-08-12. Forty candidates in `starplast/data/icons/`, black and white, for the user to
pick from.

## What the mark has to carry

The name is starplast -- a star map of plastid-bearing parasites. The application is a 3D point
cloud of 8,140 genes where position means similarity and grey means unknown. Anything that reads as
a cell diagram is wrong; that is the artwork in `Apicomplexa_cells.svg` and a different job.

Directions worth covering across the forty rather than forty variations on one:

- a point cloud or constellation, which is literally what the map is
- the apicoplast, the plastid the name refers to
- the crescent of a tachyzoite, the most recognisable shape in the field
- an orbit or a ring, for the three levels of detail
- a letter S built from points
- something that encodes the project's actual argument: most of the field is dark

## Constraints

- Black and white only, no greys that vanish when printed small.
- Must survive at 16px, since it becomes the window and tab icon. Test that rather than assuming.
- SVG, so it scales and can be recolored per theme later.
- One file per candidate, numbered, so the user can name the ones they like.

## Done when

Forty distinct SVGs are in the icons directory, each legible at 16px, and none of them is a cell
diagram.
