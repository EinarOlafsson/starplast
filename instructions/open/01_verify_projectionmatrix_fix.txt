STATE
    Clicking a gene raised, repeatedly:

        TypeError: GLViewMixin.projectionMatrix() missing 2 required

    pyqtgraph has changed this signature twice: no arguments, then
    (region=None), now (region, viewport). The development machine has 0.13.7

    Map3D._mvp() in app.py now tries all three forms in order, and

    on every subsequent click.

    be tested here; 0.13.7 never takes that path.

    crosslink models, selection-scoped edges, the LOD system tier. If this is
    still broken, the rest of the application is decoration.

    click. If it works, add tests/test_gl_compat.py pinning all three
    signatures with a stub so it cannot regress. If it does not, get the new
    traceback -- the fallback chain is in Map3D._mvp.

    Clicking a gene fills the evidence panel and prints nothing to the console.
    `w.view.project()` returns 8,140 finite screen positions.
