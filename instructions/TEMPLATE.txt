================================================================================
<TITLE — what the task is, in one line>
================================================================================

STATE
    What is true right now. Measured, not assumed. If a number is quoted, say
    where it came from and when it was checked.

WHY IT MATTERS
    What goes wrong if this is left. If the answer is "nothing much", say so
    and close the file -- a decision not to act is a result.

WHAT TO DO
    Concrete steps. File paths and function names, not intentions.

HOW TO KNOW IT WORKED
    The check that distinguishes done from looks-done. A test, a number, a
    render. "It runs" is not a check.

TRAPS
    Anything that already caught someone here.
