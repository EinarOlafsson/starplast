================================================================================
DONE -- 2026-08-12. THE NEGATIVE CONTROL FAILED, AND THAT IS THE RESULT.
================================================================================

Four targets, 328 runs each, 41 dataset combinations x 2 n_neighbors x 2
min_dist x 2 min_cluster_size, 3,000-gene seeded subsample, seed 42. About 20
minutes per target.

    stage_enriched_derived   0.709   POSITIVE control -- must be high
    attention_depth          0.654   NEGATIVE control -- must be LOW
    cellcycle_phase          0.489   measured
    compartment              0.484   measured

THE NEGATIVE CONTROL OUTSCORED BOTH MEASURED TARGETS.

    Read literally that says the map recovers how much a gene has been STUDIED
    better than it recovers where the protein is or when it is expressed --
    which is what this file said would mean the features encode study effort.

    The per-label breakdown says something more precise and more useful. Almost
    all of attention_depth's 0.654 comes from ONE class: the never-named genes,
    at F1 0.77 over 1,439 of them. Its real tiers score badly -- incidental
    0.35, focal 0.21, substantive 0.14. The map is not ranking attention. It is
    separating genes that have been MEASURED from genes that have not.

    And that is a property of missingness, not of the literature: a gene absent
    from most assays is absent from most of the feature matrix.

WHICH MEANS COMPARTMENT'S HEADLINE WAS THE SAME ARTEFACT

    compartment's single best-recovered label was `unassigned` at F1 0.39. Its
    real compartments sit at 0.21-0.35: cytosol 0.35, dense granules 0.28,
    nucleus-chromatin 0.26. Excluding the pseudo-label, the same run scores
    0.207 rather than 0.484.

    hyperLOPIT assignment tracks abundance, so `unassigned` is largely "too
    scarce to call" -- the same measured/unmeasured axis again.

CELL CYCLE IS THE ONE TARGET WITH A REAL SIGNAL

    All of its labels are genuine phases; there is no absence class. C 0.54,
    S 0.53, M 0.37, G1b 0.25, from expression_summary + fitness_screens +
    published_screens at nn=15, mcs=60.

    So the honest ranking of biology recovered from structure is:
        cell-cycle phase   0.489   (real labels throughout)
        localisation       0.207   (once absence is excluded)

    Which reverses the assumption the project started from. Location was the
    target that had data; cell cycle turns out to be the one the map actually
    organises.

FIXED, NOT JUST NOTED
    score_recovery now excludes labels meaning "not measured" -- unassigned,
    unknown, empty, nan -- from scoring, with the exclusion overridable because
    "does the map separate measured from unmeasured" is a legitimate question,
    just not a biological one. Every number above is reproducible; the ones
    quoted as headlines were computed before this change and are marked.

WHAT THIS DOES NOT MEAN
    Not that the map is worthless. It means held-out recovery of a label with
    an absence class measures coverage, and any comparison against such a
    target has to exclude it. The three surviving numbers -- 0.709 positive
    control, 0.489 cell cycle, 0.207 localisation -- are internally consistent
    and behave exactly as they should.

STILL TO DO

      the step that turns a recovered structure into named predictions for the
      unlabelled genes in each pure cluster, and it is the whole point of
      finding a structure that recovers something.
    * Re-run all four targets now that absence labels are excluded, so the
      headline table is computed under one rule rather than two.
    * The grid is still 2x2x2 on a 3,000-gene subsample. A full-proteome run
      over a wider grid is hours, which is fine unattended.
