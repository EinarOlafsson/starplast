================================================================================
THE 40 INTERACTION STUDIES WITH NO SUPPLEMENTARY FILES ON DISK
================================================================================

STATE
    97 tagged-protein interaction studies were catalogued from the abstract
    corpus. 38 now yield identifiers -- 32 from spreadsheets, 6 more once the
    PDFs and DOCX were read.

    Of the 59 that do not: 40 have NO files at all. Europe PMC's
    supplementaryFiles endpoint returned 404 for them. That is not a parsing
    failure, and the earlier framing of "65 unread documents" overstated what
    is recoverable. Only 25 ever had anything to read; 20 of those gave
    something up.

WHY IT MATTERS
    Marginal. The parsed studies already produce 68,085 memberships over 7,912
    genes, and membership is not interaction anyway (see 00_INDEX). More
    membership rows do not move any conclusion.

WHAT TO DO
    Probably nothing. If it is ever wanted, it means fetching from each
    publisher individually -- Elsevier, Wiley and Springer each need their own
    handling, some behind paywalls -- for data that still needs per-paper
    curation before it becomes an edge.

    Better use of the same effort: curate hit lists from the 38 studies that DO
    parse. That is what would turn membership into interactions, which is the
    thing actually missing.

HOW TO KNOW IT WORKED
    Not applicable unless attempted. If attempted, the check is the same as for
    curation: does a named bait connect to a named set of hits, with the
    paper's own threshold column cited.

TRAPS
    Do not resume the framing that these are 40 documents waiting to be parsed.
    They are 40 studies whose supplementary data is not accessible from here.


================================================================================
DECIDED 2026-08-11 -- drop them, but only after checking for a databank
================================================================================

User instruction: "if there is no supplementary data and there is no data the
papers point towards saved in a databank that is clearly labeled, then drop
them."

So this is NOT simply closed as not-worth-doing. There is a check to run first,
and it is cheap:

    for each of the 40 studies with no supplementary file
        look in the paper for a databank accession -- GEO, PRIDE, ArrayExpress,
        SRA, Dryad, Zenodo, figshare
        CLEARLY LABELLED is the test: an accession stated as holding this
        paper's data. A bare mention of a database is not a deposit.
        if found  -> fetch it; it is a real dataset that was simply not
                     attached to the article
        if absent -> drop the study, and record it as dropped WITH THE REASON

Recording the drop matters as much as the drop. A future session asking "why
are these 40 papers not in the corpus" must find the answer here rather than
re-deriving it, and "we checked, there is genuinely nothing" is a finding.

Note what this changes: the earlier conclusion in this file was that the 40 are
not worth the effort. That was an effort judgement. The instruction replaces it
with an evidence judgement -- check first, then drop what is genuinely empty.
Some of the 40 may turn out to have deposited data that was never attached to
the article, which is common and would make them worth having.


================================================================================
DONE -- 2026-08-11. CHECKED, THEN DROPPED.
================================================================================

The instruction was check-then-drop, not drop. The check was run properly and
it changed what could be concluded, so the evidence is recorded here in full.

METHOD
    A first pass read each paper's open-access full text and searched for the
    accession patterns twelve archives issue. It found nothing -- but it could
    only READ 7 of the 40, because the other 33 have no open-access full text.
    "No deposit found" there meant "not checked", which is not the same claim,
    and dropping on it would have been dropping on absence of evidence.

    Second pass, which does not need the full text:
      * Europe PMC `resultType=core` -> dbCrossReferenceList, the CURATED links
        from a paper to records in PRIDE/EMBL/GEO. Someone asserted these; they
        are not inferred from prose. This is "clearly labelled" made
        operational.
      * the annotations API, which text-mines accessions from ABSTRACTS as well
        as full text.

RESULT
    curated database cross-reference        5 of 40   (4 PRIDE, 1 EMBL)
    any text-mined identifier               8 of 40
    Europe PMC believes supplementary exists 7 of 40

    The text-mined identifiers are mostly not deposits. Addgene and RRID are
    reagent identifiers; 10.15252/... and 10.21769/... are cited papers and a
    protocol; NM_001122603 and Q08168 are RefSeq and UniProt records that
    already existed; PF04096 is a Pfam domain. All are references to other
    people's records, not this paper's data.

    The four PRIDE deposits, all resolved and inspected:

        PXD063409  11 files   SEARCH 8, RAW 2, OTHER 1     no RESULT at all
        PXD065533  39 files   RAW 36, RESULT 1             one .mzid
        PXD009604  98 files   PEAK 64, RESULT 16, RAW 2    .mzid.gz
        PXD004083  60 files   PEAK 24, RAW 12, RESULT 12   .mzid.gz, a
                                                           methylation scan

    Every RESULT file is mzIdentML: peptide-spectrum IDENTIFICATIONS, not
    per-protein quantification. That is the same finding the index already
    records for PXD019729, PXD065585 and PXD043808, now confirmed across four
    more deposits. Seven for seven.

DECISION
    All 40 dropped, per the instruction: no supplementary data, and no clearly
    labelled databank holding data these papers point to.

    The four PRIDE accessions are named above rather than merely counted, so
    that a future session asking "was anything deposited" finds the answer and
    the reason instead of re-deriving it. mzIdentML would yield a protein
    identification list -- that is, membership -- and membership is not
    interaction. The parsed studies already produce 68,085 memberships over
    7,912 genes; four more identification lists move no conclusion.

WHAT WOULD CHANGE THIS
    A search engine run over the RAW deposits, producing quantification rather
    than identification. That is a different project, and it is the same
    conclusion the sources module reached for GEO versus PRIDE: GEO deposits
    processed matrices and can be automated end to end, PRIDE deposits
    instrument output and cannot.
